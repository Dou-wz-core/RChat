// 业务流程
//==================================
// ChatServer启动流程

main()
  ↓
ChatService::instance()
  ├─ 首次构造业务单例
  ├─ 尝试将数据库用户状态重置为 offline
  └─ 注册 msgid → login / reg / logout / oneChat
  ↓
创建主 EventLoop
  ↓
创建 InetAddress("127.0.0.1", 6000)
  ↓
构造 ChatServer， 注册连接和消息事件回调
  ├─ 构造 Muduo TcpServer
  ├─ 注册 ChatServer::onConnection
  ├─ 注册 ChatServer::onMessage
  └─ setThreadNum(4)
  ↓
ChatServer::start()，Muduo 开始监听服务器端口
  ↓
TcpServer::start()
  ├─ 启动 4 个 subLoop I/O 线程
  └─ 监听服务端口，并关注监听 socket 的可读事件
  ↓
主线程 loop.loop()
  ↓
mainLoop 等待并处理新连接等事件
subLoop 等待并处理各自连接的读写事件

//==================================
// 一次聊天业务流程
客户端 A 启动 Telnet
    ↓
Telnet 创建客户端 socket
    ↓
调用 connect()
    ↓
向 127.0.0.1:6000 发起 TCP 连接
    ↓
操作系统收到连接请求
    ↓
Muduo TcpServer 接收连接
    ↓
Muduo 为客户端创建 TcpConnection
    ↓
触发 ChatServer::onConnection(conn)
    ↓
客户端 A（发送方）
    │
    │ 发送 JSON 字符串
    │ {"msgid":5,"id":1,"from":"zhang san","to":2,"msg":"hello"}
    ▼
网络传输
    ↓
服务器 TCP 协议栈
    ↓
服务器 socket 接收缓冲区  
    ↓
┌──────────────────────────────────────────────┐
│ 我的 ChatServer                              |
│                                              │
│  Muduo EventLoop 检测到可读事件               │
│        ↓                                     │
│  Muduo 接收 TCP 数据                          │  
│        ↓                                     │
│  Muduo 触发回调 ChatServer::onMessage()       │
│        ↓                                     │
│  json::parse()                               │
│        ↓                                     │
│  根据 msgid=5 找到 oneChat() 等消息专属回调    │
│        ↓                                     │
│  根据 to=2 查询 _userConnMap                  |
│        ↓                                     │
│  得到用户 2 的 TcpConnectionPtr targetConn    │
│        ↓                                     │
│  targetConn->send(js.dump())                 │
└──────────────────────────────────────────────┘
    │
    │ Muduo 将数据写入服务器 socket，发送到客户端 B 的 TCP 连接
    │
    ▼
服务器 TCP 协议栈
    │
    │ 通过网络发送 TCP 数据包
    ▼
客户端 B 的 TCP 协议栈
    │
    │ TCP 重组数据、校验、按序交付
    ▼
客户端 B 的 socket 接收缓冲区
    │
    ├── 如果是 Telnet
    │       ↓
    │   Telnet 读取 socket 数据
    │       ↓
    │   直接打印到终端
    │
    └── 如果是自己写的客户端
            ↓
        客户端的 recv/read 或 Muduo 回调
            ↓
        读取接收缓冲区
            ↓
        按协议拆分完整消息
            ↓
        json::parse()
            ↓
        根据 msgid 判断消息类型
            ↓
        显示聊天内容或交给业务处理
